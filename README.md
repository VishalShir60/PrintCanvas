## 📖 Overview

PrintCanvas is a full-stack Print-on-Demand web application that provides customers with an intuitive online shopping experience. Users can browse products, filter by categories, view product details, manage their cart, and securely place orders.

The application is designed using modern web technologies with a scalable architecture and responsive UI.

- 🛍️ Browse premium products

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/VishalShir60/PrintCanvas.git
```

Move into the project directory

```bash
cd PrintCanvas
```

---

## Install Frontend

```bash
cd client
npm install
```

---

## Install Backend

```bash
cd ../server
npm install
```

---

# ▶️ Run Frontend

```bash
cd client
npm run dev
```

Runs on

```
http://localhost:5173
```

---

# ▶️ Run Backend

```bash
cd server
npm start
```

or

```bash
npm run dev
```

Runs on

```
http://localhost:5000
```

---

# 🔧 Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000

MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```
